# واتساپ چت - اپلیکیشن چت با Django

یک اپلیکیشن چت شبیه واتساپ با Django و Python که امکان ثبت‌نام، افزودن مخاطب با شماره تلفن، تأیید/رد درخواست و چت لحظه‌ای را فراهم می‌کند.

## ویژگی‌ها

- **ثبت‌نام و ورود** با شماره تلفن
- **افزودن مخاطب** با دکمه + و وارد کردن شماره تلفن
- **تأیید یا رد درخواست** مخاطب توسط طرف مقابل
- **چت لحظه‌ای** با WebSocket (Django Channels)
- **رابط کاربری فارسی** با طراحی شبیه واتساپ

## نصب و اجرا

```bash
cd whatsapp_chat
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py runserver
```

سپس مرورگر را باز کنید: http://127.0.0.1:8000

## نحوه استفاده

1. دو کاربر مختلف ثبت‌نام کنید (با شماره تلفن‌های متفاوت)
2. کاربر اول با دکمه **+** شماره کاربر دوم را وارد کند
3. کاربر دوم از آیکون زنگوله درخواست را ببیند و **تأیید** یا **رد** کند
4. پس از تأیید، هر دو می‌توانند با هم چت کنند

## ساختار پروژه

```
whatsapp_chat/
├── accounts/          # مدیریت کاربران (ثبت‌نام، ورود)
├── chat/              # مخاطبین، پیام‌ها، WebSocket
├── config/            # تنظیمات Django
├── static/            # CSS و JavaScript
├── templates/         # قالب‌های HTML
└── manage.py
```

## تکنولوژی‌ها

- Django 5+
- Django Channels (WebSocket)
- Daphne (ASGI server)
- SQLite

## ایجاد ادمین (اختیاری)

```bash
python3 manage.py createsuperuser
```

سپس به `/admin/` بروید.
